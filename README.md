# AI/ML Developer Portfolio

A modern, professional portfolio website showcasing expertise in AI/ML systems, backend development, and RAG (Retrieval-Augmented Generation) technologies.

## 🌟 Features

- **Modern Design**: Clean, professional UI with beautiful gradients and animations
- **Dark Mode**: Seamless theme switching with system preference detection
- **Responsive**: Mobile-first design that looks great on all devices
- **Interactive**: Smooth animations and hover effects using Framer Motion
- **Performance Optimized**: Built with Vite for fast loading and development

## 🚀 Technologies Used

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Animations**: Framer Motion for smooth, professional animations
- **UI Components**: shadcn/ui for consistent, accessible components
- **Styling**: Custom design system with semantic tokens
- **Icons**: Lucide React for modern, scalable icons
- **Build Tool**: Vite for fast development and optimized production builds

## 📋 Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About**: Detailed background and expertise highlights
3. **Skills**: Interactive skill tags organized by category
4. **Projects**: Showcase of key projects with tech stacks and descriptions
5. **Contact**: Multiple ways to get in touch with social links

## 🎨 Design System

The portfolio uses a comprehensive design system built on:
- **Color Palette**: Professional blue and purple gradients
- **Typography**: Modern, readable font stack
- **Animations**: Subtle, performance-optimized transitions
- **Components**: Reusable UI components with consistent styling
- **Dark Mode**: Seamless theme switching

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
